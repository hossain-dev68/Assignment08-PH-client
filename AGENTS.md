# studio-space

Single Next.js 16 App Router app — no monorepo, no CI, no test runner, no typecheck script. Entry points: `src/app/layout.tsx`, `src/app/page.tsx` (currently an empty shell). Path alias `@/*` → `src/*`. Code lives under `src/`: `components/ui/` (shadcn output), `lib/`, `hooks/` (hand-written).

## Commands

Use **npm** (the lockfile is `package-lock.json`; ignore the yarn/pnpm/bun variants in README).

- `npm run dev` — dev server on :3000, Turbopack
- `npm run build` — production build; it also runs the TypeScript check, so it doubles as a typecheck
- `npm run lint` — runs `eslint` (flat config in `eslint.config.mjs`) over the repo; one file: `npx eslint src/path/file.tsx`
- `npx tsc --noEmit` — typecheck only

Gotchas:

- **Lint currently fails with 2 pre-existing errors** (`react-hooks/set-state-in-effect`) in shadcn scaffold files: `src/components/ui/carousel.tsx` and `src/hooks/use-mobile.ts`. They are not yours — just don't add new ones.
- **Typecheck on a clean checkout fails** with `Cannot find name 'LayoutProps'`: `next-env.d.ts` and `.next/types/**` are gitignored and generated by `next dev`/`next build`. Run one of them once first.
- There is no `format`/`prettier` script; don't add formatting churn.

## Next.js 16 specifics

- Bundled docs are the source of truth: `node_modules/next/dist/docs/` (see block above). For breaking changes start at `01-app/02-guides/upgrading/version-16.md`.
- `next.config.ts` enables `cacheComponents` + `partialPrefetching`: caching uses the new `"use cache"` / `cacheLife` / `cacheTag` model, not fetch-level `revalidate` — see `01-app/01-getting-started/08-caching.md`.
- `reactCompiler: true` — React Compiler is on.
- Pages/layouts take the **generated global prop types** `PageProps<'/route'>` / `LayoutProps<'/route'>` (declared in `.next/types/routes.d.ts`, don't hand-roll them). `params` and `searchParams` are Promises: `await props.params`.

## UI stack: shadcn "base-nova" on Base UI

- Primitives are `@base-ui/react` — **not Radix**; there are no `@radix-ui/*` imports in this repo.
- ~70 components are vendored in `src/components/ui/`. Treat them as generated: add via `npx shadcn add <name>` (or `add <name> --diff` to preview; `shadcn diff` is deprecated) instead of hand-editing.
- `cn` is imported from the npm package `"cn"` (`import { cn } from "cn"`), not from `@/lib/utils` — `src/lib/utils.ts` exists only to satisfy the shadcn `utils` alias.
- Tailwind **v4, CSS-first**: no `tailwind.config.*` or `postcss.config.*`. Theme and design tokens live in `src/app/globals.css` (`@theme inline` + CSS variables). CSS is processed by the `@tailwindcss/turbopack` loader rule in `next.config.ts` — do not add a PostCSS config.
- `globals.css` does `@import "shadcn/tailwind.css"` from the `shadcn` dependency (`npx shadcn eject` inlines it).
